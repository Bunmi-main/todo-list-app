# 🎯 Task & Goal Tracker (Todo List App)

A clean, responsive, and feature-rich Todo & Goal Tracker web application built with vanilla **HTML5**, **CSS3**, and **JavaScript**. Runs entirely client-side in the browser with `localStorage` persistence—no servers, backend, or databases required.

![License](https://img.shields.io/badge/license-MIT-blue.svg)
![Status](https://img.shields.io/badge/status-active-success.svg)

---

## ✨ Features

- **🎯 Task & Goal Mapping**: Pair every daily task with an overarching goal to stay purpose-driven.
- **⚡ Daily Task Strength Bar**: Real-time momentum meter tracking today's progress from 0% to 100% with dynamic motivational encouragement.
- **📋 Sub-tasks / Action Steps**: Break down complex goals into bite-sized steps right on the task card or edit dialog.
- **⏰ Expiration / Due Dates**: Set target dates and times with automatic smart badges for *Upcoming*, *Due Today*, and *Overdue*.
- **☀️ Light & 🌙 Dark Mode**: Beautiful light and dark themes with persistent user preference.
- **👋 Personalized Welcome**: Smart greeting banner that recognizes returning users and lets you set a custom name.
- **🎉 Achievement Celebrations**: Displays *"You crushed it. Well-done!"* on all completed tasks along with a celebratory toast notification.
- **🔍 Real-Time Search & Filtering**: Instant search across tasks, goals, and sub-tasks, plus filter tabs for *All*, *Not Achieved*, and *Achieved*.
- **💾 LocalStorage Persistence**: All your tasks, subtasks, theme settings, and preferences stay saved on your device across refreshes.
- **📱 Mobile-First Responsive**: Built with touch-friendly controls and fluid flexbox layouts that look great on phones, tablets, and desktops.

## 🚀 Getting Started

No build tools or installation needed! Simply open `index.html` in any modern web browser:

1. Clone or download this repository:
   ```bash
   git clone https://github.com/Bunmi-main/todo-list-app.git
   cd todo-list-app
   ```
2. Double-click `index.html` or open it with your favorite browser:
   - Google Chrome
   - Microsoft Edge
   - Mozilla Firefox
   - Apple Safari
